# Thesis Literature

Literature collected for my bachelor's thesis.

**Topic:** A mobile app for monitoring food intake through voice commands, with nutritional values taken from a custom food database.

## Repository structure

```
papers/          PDFs of the open-access sources
notes.md         what is relevant in each source and which part of the thesis it supports
references.bib   complete bibliographic information for all sources (BibTeX)
```
